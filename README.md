# BOUT++ And SOLPS-ITER Coupled Self-consistently (BASICS)

The BASICS package self-consistently couples SOLPS-ITER and the BOUT++ ELM-6f model. 
The package includes reader files for EQDSKs, b2fstate, b2fplasmf, and b2fgmtry.
